# SnapSheet

Browser app that turns lecture screenshots into print-ready A4 PDFs.

Screenshots stay on your device. There is no account, no OCR, and no cloud AI.

## Run

```bash
bun install
bun run dev
```

## What it does

1. Drop JPG, PNG, or WEBP screenshots (HEIC if the browser can decode it).
2. Reorder, rotate, crop, or delete.
3. Smart print optimization converts dark slides to ink-friendly pages without flattening photos or colored diagrams.
4. Auto layout packs questions onto A4 with cut guides.
5. Download or print an A4 PDF.

Use **Try sample slides** to exercise white slides, dark slides, diagrams, photos, mixed content, margins, portrait, landscape, and high-resolution captures.
